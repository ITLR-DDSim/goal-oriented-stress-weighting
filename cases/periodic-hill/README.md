# Periodic hill

Training case: `alpha_1p2/`. Test cases: `alpha_1p0/` and `alpha_1p5/`.

OpenFOAM v1912 with `RASModel kOmega`. Each case contains initial/boundary fields (`0/`), physical and turbulence settings and the mesh (`constant/`), and numerical, run and sampling controls (`system/`). Run `simpleFoam` in the case directory; see each case README for its settings.

Reference DNS: Xiao et al. (2020); data are not included.
