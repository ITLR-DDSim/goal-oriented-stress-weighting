# square-duct: Re_b_2600

Training condition. OpenFOAM v1912 baseline with `RASModel kOmega`, solved with `simpleFoam`.

| Item | Setting |
| --- | --- |
| Reynolds number | Re_b = U_b h / nu = 2600, with half-width h = 0.5, U_b = 1 and `nu` = 1.923e-4 |
| Flow driving | `meanVelocityForce` in `system/fvOptions`, U_b = 1 |
| Mesh | one quarter of the cross-section (`symmetryPlane` on `topSym` and `rightSym`), 50 x 50 cells graded towards the walls, one cell in the `cyclic` streamwise direction; generated by `blockMesh` |
| Convection | U: `bounded Gauss linearUpwind grad(U)`; k, omega: `bounded Gauss upwind` |
| Walls | U no-slip; k `kqRWallFunction`; omega `omegaWallFunction`; nut `nutkWallFunction` |
| Initial fields | uniform: U = (1 0 0), k = 8.71215e-4, omega = 0.8435, nut = 0, p = 0 |

## Run

```sh
blockMesh
simpleFoam
```

The run takes 10000 SIMPLE iterations (initial Ux residual below 1e-12 at the end). As for any linear eddy-viscosity
model, the k-omega baseline has no secondary flow in the cross-section.

No reference data or learned closure is included.
